# Приличный карась — лендинг рыболовного магазина

Проект выполнен в лабораторных работах №4 и №5 (ГУАП, каф. №42, студент Э. Э. Врубель, гр. 4621).

## Тематика
Рыболовный магазин «Приличный карась»: снасти, приманки, катушки, удилища, экипировка.

## Целевая аудитория
Начинающие и опытные рыболовы 20–65 лет, интересующиеся активным отдыхом и природой.

## Цель сайта
Представить магазин как надёжного поставщика, показать ассортимент и мотивировать пользователя связаться с магазином.

## Технологии
- HTML5
- CSS3 (Grid, Flexbox)
- Git, GitHub, GitHub Pages
- Без JavaScript и внешних библиотек

## Структура проекта
- `index.html` — одностраничный лендинг (HTML + CSS в одном файле).
- `assets/images/` — локальные изображения сайта.
- `README.md` — описание репозитория.
- `.gitignore` — исключения для Git.

## Как создан
Лендинг сгенерирован большой языковой моделью **Qwen** (ЛР4), доработан ИИ-агентом **SourceCraft Code Assistant** (ЛР4), а в ЛР5 проект ведётся через **Git/GitHub** с ветвлением, Pull Request и публикацией на GitHub Pages.
